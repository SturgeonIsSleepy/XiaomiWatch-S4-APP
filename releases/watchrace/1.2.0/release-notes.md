# 迷你赛车 v1.2.0 · 长按加速与自由跟随

- 喇叭取消冷却：每次点击立即响应；连续鸣笛刷新前车短暂提速时间，不叠加提速幅度。
- 按住驾驶区域加速，松开自动刹车到普通车40 km/h。取消独立刹车按钮。
- 车辆在道路范围内连续跟随手指横向、纵向移动，取消三车道吸附；拖动路径参与碰撞检测。
- 最高速度从约111提高到187 km/h，加速率从85提高到300逻辑像素/秒²，约1.1秒从普通车速度到最高速。
- 可一指驾驶、另一指鸣笛；后台、暂停、熄屏、触摸取消或驾驶手指丢失时松油门。保留单定时器、对象复用与最高里程。

安装 `com.sapnapboy.watchrace.debug.1.2.0.rpk`，包名不变，versionCode3，可更新旧版。

11项基础自动测试与官方S4模拟器短操作检查通过；实体音效、多点触控手感、帧率和温控未验证，未进行压力测试。
