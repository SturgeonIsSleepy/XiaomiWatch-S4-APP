# 迷你赛车 · Watch S4 · v1.2.0

小米 Watch S4 标准版赛车，包名 `com.sapnapboy.watchrace`，versionCode3。兼容旧版最高里程。

## 新操作

- **按住屏幕加速**：在道路驾驶区域按住，即开始加速，保持按住持续加速到上限。
- **拖动跟随**：车辆连续跟随驾驶手指的横向和纵向位置，不再按三车道跳格换道。位置限定在道路安全范围内；手指在道路外时，车辆停在对应边界。
- **松手自动刹车**：松开驾驶手指立即松油门、开始减速，降到普通车40 km/h并保持相对跟车距离。保留减速过程，不能消除已经发生的碰撞。
- **喇叭无冷却**：每次按下都立即响应，可以连续点击。让当前车辆正前方最近的可见前车短暂提速1.6秒；连续鸣笛刷新持续时间，提速幅度不叠加。前车提速仍受前方68像素安全间距限制。

底部保留喇叭按钮，取消单独刹车按钮和左右换道箭头。左下方显示当前加速/松手刹车状态。鸣笛按钮不会抢占驾驶手指，可一指驾驶、另一指点喇叭；两指逻辑通过基础测试，实体多点体验需真机验证。

右上角“Ⅱ”暂停，“继续驾驶”恢复。后台、熄屏、暂停、触摸取消或驾驶手指丢失均清理油门，恢复后默认自动刹车，需要重新按住才加速。碰撞后可再来一局；保存最高里程，当前局不跨进程恢复。

## 提速与碰撞

最高速度从原版250提高为420逻辑像素/秒，显示约187 km/h（原约111）；加速率从85提高为300逻辑像素/秒²，从普通车40 km/h起约1.1秒到最高速；松手减速率360，约0.92秒从最高速刹到普通车速度。速度/里程为游戏刻度。

车辆坐标每个游戏帧跟随最新触摸点，不加车道吸附或转向缓动。驾驶范围中心x131–335、y170–352（466×466设计坐标）。碰撞同时检查横向与纵向的帧内相对路径，防止快速拖动直接穿过前车。

普通车辆仍沿三条车道行驶。道路按玩家实际速度滚动，普通车按玩家与普通车的相对速度移动；普通车固定90逻辑像素/秒，鸣笛临时增加24（约10.7 km/h）。

## 负载与音效

单游戏定时器约20Hz；固定4个交通车辆、8个虚线记录和4项车辆位置快照，复用记录。触摸移动只更新最新目标坐标，实际位置/样式合并到游戏帧处理，不为每次触摸创建动画或定时器。单帧最多推进100ms，不追补大量迟到帧。暂停、结束、后台停止刷新，不主动常亮。

喇叭音效为原创合成短音，不循环，不强制设置系统音量。连续点击重用同一个播放器，重启当前短音，不排队叠播。音频异常时保留无冷却鸣笛的玩法及视觉反馈。暂停、结束或后台停止仍在播放的本游戏短音。

代码限制不能保证实体帧率或排除温控重启。
