# 迷你赛车 · Watch S4 · v1.1.0

小米 Watch S4 标准版三车道赛车，包名 `com.sapnapboy.watchrace`。兼容原版最高里程，versionCode2。

## 操作

左右滑动，或点击道路下半部左右侧换道。新增底部两个独立控制区，触碰不会同时换道：

- **按住刹车**：逐渐降到普通车的40 km/h；保持按住，与未加速的普通车保持相对距离。松开后逐渐恢复巡航速度。刹车需要减速过程，不能消除已经发生的碰撞。
- **喇叭**：点击使当前实际车道中、最近且可见的前车短暂提速。默认加速约10.7 km/h，持续1.6秒，冷却2.5秒；受前方68像素安全间距约束，避免普通车彼此重叠。没有目标时正常鸣笛并显示“无前车”。

喇叭成功响应时按钮显示“前车提速”，目标车边框高亮，之后显示冷却秒数。附带原创合成的0.2秒短鸣笛音效，不循环，不强制设置系统音量。系统静音、音频不可用时仍保留玩法和视觉反馈。

可以一指按住刹车、另一指点喇叭。刹车手指移出按钮、松开、触摸取消、暂停或进入后台时都会释放刹车；不会恢复后继续卡在刹车状态。双指并用由基础逻辑测试覆盖，实体多点触控体验仍需手表验证。

右上角“Ⅱ”暂停，点“继续驾驶”恢复。后台自动暂停；返回后手动继续。碰撞后“再来一局”。显示的速度与里程为游戏刻度。最高里程保存，当前局不跨进程恢复。

## 运动与负载

道路按玩家实际速度滚动，前车按“玩家速度减普通车速度”移动。普通车速度固定为90逻辑像素/秒（显示40 km/h）；巡航速度随里程从140升至最高250。刹车减速率160逻辑像素/秒²，松开加速率85。鸣笛临时增加前车24逻辑像素/秒，作用时间按游戏推进时间计，暂停时冻结。

驾驶时单定时器约20Hz，固定4个交通车辆和8个虚线记录。暂停、结束、后台停止刷新；单帧最多推进100ms，不追补大量迟到帧。鸣笛效果、冷却、前车加速复用同一游戏更新，没有额外定时器。刹车时生成车辆会检查入口间距；被喇叭催促的车辆受前方安全间距限制。暂停、结束和后台停止仍在播放的本游戏短音效。

不主动常亮，没有循环背景音乐、联网或物理引擎。代码负载限制不能保证真机帧率或排除温控重启。
