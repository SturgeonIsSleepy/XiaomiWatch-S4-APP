# 迷你赛车 v1.1.0 · 刹车与喇叭

- 底部按住刹车：逐渐降至普通车40 km/h，保持相对跟车距离；松开后恢复巡航加速。
- 点喇叭：同车道最近的可见前车短暂增加约10.7 km/h，持续1.6秒、冷却2.5秒。受前方安全间距限制，避免车辆相互重叠。
- 目标车边框高亮、按钮提示和冷却倒计时，附带不循环的短促鸣笛音效。音频不可用时保留游戏与视觉反馈。
- 控制按钮不会触发换道；支持刹车和喇叭两指并用，离开按钮、取消、暂停或后台自动释放刹车。
- 保留单定时器、固定车辆/虚线记录、暂停/后台停止刷新，兼容旧版最高里程。

安装 `com.sapnapboy.watchrace.debug.1.1.0.rpk`，包名不变，versionCode2，可更新旧版。

10项基础自动测试与官方S4模拟器短流程检查通过。模拟器禁用音频输出、音频后端不可用，实体鸣笛音效与双指体验未验证。未进行压力或真机温控测试。
