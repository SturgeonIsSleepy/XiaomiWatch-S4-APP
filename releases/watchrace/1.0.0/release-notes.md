# 迷你赛车 v1.0.0

面向小米 Watch S4 标准版的简易三车道赛车。

- 左右滑动或点击画面下方左/右侧换道，避开来车。
- 按行驶里程计分，逐渐提速并封顶，保存最高里程。
- 支持暂停、手动继续和碰撞后重开；后台自动暂停。
- 固定车辆/虚线记录、驾驶时单定时器约20Hz；暂停、结束、后台停止刷新，限制延迟帧推进量。

安装 `com.sapnapboy.watchrace.debug.1.0.0.rpk`；独立包名 `com.sapnapboy.watchrace`，不会覆盖其他游戏。

仅做6项基础自动测试和官方S4模拟器短流程验证，未进行压力测试。实体手表的触控手感、功耗、温控与帧率尚未验证。
