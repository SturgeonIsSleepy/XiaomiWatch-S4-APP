# 迷你赛车 · Watch S4 · v1.0.0

面向小米 Watch S4 标准版的三车道躲避赛车。独立应用，包名 `com.sapnapboy.watchrace`，不会覆盖2048或跳一跳。

## 玩法

点击“开始驾驶”，左右滑动换一条车道，也可以点击画面下方左/右侧换道。避开前方车辆，按行驶里程计分；速度随里程缓慢上升并封顶。车身碰撞后结束，点“再来一局”重新开始。显示的 km/h 为游戏速度刻度。

右上角“Ⅱ”暂停，再点“继续驾驶”恢复。退到后台或熄屏时暂停，回到页面后需手动继续，避免恢复瞬间撞车。最高里程保存在本地；当前行驶进度不跨进程恢复。

## 运行负载

驾驶时单定时器约20次/秒更新，空闲、暂停、结束与页面隐藏时停止刷新。不主动常亮，没有音乐、联网、物理引擎或震动任务。固定4个交通车辆记录、8个虚线记录，通过位置更新复用；换道约0.11秒走完一条车道。帧延迟超过100ms时只推进100ms，避免补帧集中消耗；因此持续卡顿时游戏时间会变慢。

碰撞使用帧内路径检测，检查换道和交通车辆在同一时间的位置，减少延迟帧穿透。单次生成一辆车，初期间隔1.5秒，最快0.92秒；车道可随机重复。速度从140逻辑像素/秒升至最高250。

这些是代码层负载限制，不能保证真机帧率或排除温控重启。

## 构建

```sh
npm ci
npm test
npm run build
```

aiot-toolkit2.0.5，Node.js24 / Linux。输出为debug RPK：`dist/com.sapnapboy.watchrace.debug.1.0.0.rpk`，versionCode1。

仅做基础自动测试和官方S4模拟器短流程验证，不进行压力测试。实体手表的触控手感、功耗、温度与帧率尚未验证。
