# Watch S4 跳一跳 · 1.0.0

小米 Watch S4 标准版的轻量平台跳跃游戏。包名 `com.sapnapboy.watchjump`，与 2048 独立安装。

## 操作与反馈

在画面中间按住蓄力，松手起跳。按得越久，跳得越远；初始平台通常只需短按约 0.35–0.5 秒，具体随目标距离变化。

- 蓄力反馈：百分比、进度条增长、角色下压、影子变宽；接近满蓄力时进度条变为橙色。
- 松手反馈：抛物线跳跃，落地后镜头移动到下一平台。
- 落在目标平台得1分，正中中心得2分。
- 目标平台会逐渐缩小。跳远或跳近都会失误，失败后点“再来”；点“新局”重新开始。
- 保存最高分；当前局不作为跨启动存档。

蓄力达到1.1秒即封顶，继续按住不会持续刷新，也不会继续增加跳跃距离。

## 负载控制

没有常驻游戏循环，也不主动保持屏幕常亮。固定复用3个平台与角色节点：蓄力约每40ms更新，封顶即停止；飞行最多18次更新，镜头最多9次更新，目标间隔20ms。按实际经过时间跳过迟到帧，同时最多一个定时器。跳跃期间忽略再次起跳；页面隐藏/销毁时清理计时与触摸状态，并结算已有的跳跃。

## 构建

```sh
npm ci
npm test
npm run build
```

使用 aiot-toolkit 2.0.5；验证环境 Node.js 24、Linux x86_64。`dist/` 生成 debug RPK。

## 基础验证

4项自动测试通过：蓄力/距离封顶、抛物线与命中计分、蓄力反馈与封顶停止刷新、松手后结算与镜头、多点和页面隐藏时的清理。

在官方 Watch S4 466×466 模拟配置中验证：安装打开、蓄力反馈、正常落地得2分、满蓄力失误、重开，以及最高分写入。没有进行压力测试或真机温控测试。

模拟器不能验证真实芯片功耗或温度。采用上述负载限制，仍不能保证真机不会触发温控重启。
