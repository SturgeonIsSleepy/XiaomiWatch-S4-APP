# Watch S4 跳一跳 · 1.2.0

小米 Watch S4 标准版，包名 `com.sapnapboy.watchjump`。参考微信跳一跳的简洁场景和按住蓄力、松手起跳节奏，独立实现代码与图形；不包含微信素材或服务。

## 操作

主界面仅保留分数、棋子、平台和菜单。第一跳显示操作提示，成功后隐藏。右上角“•••”打开最高纪录、震动开关、重新开始与继续游戏；菜单打开时不蓄力。失误后可直接再来一局。

按得越久，跳得越远。蓄力上限从1.1秒延长至2.2秒；落点按实际按住时长计算，不会吸附到目标。

| 按住时长 | 跳跃距离（逻辑像素） |
|---|---:|
| 0.5秒 | 68 |
| 1.1秒 | 140 |
| 1.8秒 | 224 |
| 2.2秒及以上 | 272 |

平台按中、近、远循环，并加入随机偏移和左右方向变化，中心距离分别约140–160、92–112、202–222像素；对应中心命中蓄力约1.10–1.27、0.70–0.87、1.62–1.78秒。距离变化按跳跃次数推进，不受中心奖励分数影响。

蓄力反馈集中在棋子与平台下压、影子变宽和能量圈，移除百分比、进度条和常驻说明。起跳拉伸翻转，落地回弹、浮动加分与平滑镜头。中心连续命中依次加2、4、6…分，普通落地加1分并清零连击。保存最高分和震动设置，兼容旧版保存键。

## 震动与负载控制

使用 S4 支持的 `@system.vibrator.vibrate({mode:'short'})`。按下、半蓄力、满蓄力、松手与落地调用有限短震，180ms内不重复；设置关闭时不调用。无自定义强度或持续震动任务。

无常驻游戏循环，不主动常亮。蓄力40ms更新，达到2.2秒后停止刷新；飞行最多18帧，落地最多7帧，镜头最多9帧，失误最多6帧，同时最多一个定时器。飞行与镜头跳过迟到帧，隐藏或销毁清理定时器和触摸状态。实际帧率、发热与马达表现仍取决于实体手表。
