# 跳一跳 v1.2.0 · 简洁场景与慢蓄力

参考微信跳一跳的核心玩法与视觉节奏，使用独立代码和图形。

- 精简主界面：分数、棋子、立体平台；最高分、震动开关和重开收进菜单。
- 蓄力上限由1.1秒延长为2.2秒。0.5/1.1/1.8秒分别约跳68/140/224像素，时长直接决定距离。
- 近、中、远平台交替并随机偏移，距离不再集中于一个窄区间。
- 保留棋子/平台下压、空中翻转、落地回弹、中心连击、有限短震与最高分保存。
- 保留单定时器、封顶停止刷新、隐藏清理与有限动画帧数。

安装 `com.sapnapboy.watchjump.debug.1.2.0.rpk`，包名不变，versionCode3，可更新旧版。

验证仅限8项基础自动测试与官方S4模拟器短流程；未进行压力测试。实体马达震感、真机流畅度与温控未验证。
