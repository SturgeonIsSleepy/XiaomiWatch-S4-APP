## 官方模拟环境实测

- 镜像 `vela-miwear-watch-5.0/20250716`。
- 机型 `Xiaomi Watch S4` / `xiaomi_s4`，466×466。
- 系统报告：`NuttX Xiaomi Watch S4 12.3.0 ... arm miwear`。
- RPK 安装和覆盖更新成功，正常打开。
- 将测试棋盘设为 `[16,8,8,0,...]`，开启连合后实际左滑：画面显示32，得分48，只新增一个方块。见截图。
- 固定帧数动画正确结算画面。早期尝试的 CSS keyframes 在该镜像上不兼容，最终交付代码已移除，改为每阶段3帧的有界位置更新。

- 期间模拟系统全局已用内存从19,113,812字节到19,147,716字节（增加33,904字节）。这是全系统两次取样，不能单独证明长期无泄漏或真机功耗。
- 正常关闭再启动：存档分数532、连续合并开启、动画关闭均恢复；对截图16格颜色解码，与存档棋盘逐格匹配。

## 边界

没有在实体 Watch S4 上测量功耗、温度、帧率、温控重启阈值或长时间续航。模拟器短时无重启不等于真机不会重启。若真机仍易发热，可先将“动画”关闭；应用中没有永久保持屏幕常亮或后台刷新。
