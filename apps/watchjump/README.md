# Watch S4 跳一跳 · 1.1.0

小米 Watch S4 标准版平台跳跃游戏，包名 `com.sapnapboy.watchjump`。参考跳一跳的蓄力压缩、空中翻转、落地回弹与中心连击节奏，使用原创界面和素材。

## 操作与反馈

在画面中间按住蓄力，松手起跳。按得越久，跳得越远；初始目标通常需要约0.35–0.5秒，具体取决于距离。

- 蓄力：进度百分比、进度条、角色与平台同时下压、影子变宽、底部能量圈扩张。接近满蓄力变为橙色。
- 起跳：平台回弹，角色拉伸并沿抛物线翻转。
- 落地：角色压缩回弹、扩散圈、浮动加分与缓动镜头。
- 中心连击：连续命中中心依次加2、4、6…分；普通落地加1分并重置连击。
- 失误：区分跳近/跳远，角色下落，点“再来”重试。
- 保存最高分与震动设置；当前局不跨启动恢复。

顶部“震动：开/关”可控制触感，默认开启。使用官方 `@system.vibrator.vibrate({mode:'short'})`：按下、蓄力越过50%或满蓄力、松手及落地提供有限短震，180ms内不重复触发。**S4不支持 `vibrator.start/stop` 自定义持续任务**，因此没有连续振动、强度/时长调节或无限震动循环。系统关闭震动、固件限制或接口不可用时，实际体验可能不同；同步调用异常时会停用本次会话的震动，保留游戏与视觉反馈。

## 负载控制

无常驻游戏循环，不主动常亮。蓄力约40ms更新、达到1.1秒即封顶并停止刷新；飞行最多18帧，落地回弹最多7帧，镜头最多9帧，失误下落最多6帧，同时最多一个定时器。飞行与镜头按实际时间跳过迟到帧。页面隐藏/销毁清理触摸和定时器、结算已有跳跃，停止后续触感调用。S4短震由系统自行结束，不能调用该机型不支持的停止接口。

## 验证范围

7项基础自动测试，覆盖落点/计分、蓄力封顶、状态/定时器清理、震动节流与关闭/异常降级、偏好保存、落地回弹中断和连中2/4/6奖励。

官方 Watch S4 466×466 模拟环境用于检查安装、界面、蓄力、起跳和落地流程、震动接口调用与开关。**模拟器不能证明实体马达震感、强弱、噪声、功耗、温度或真机帧率**；未进行压力测试或实体手表温控测试。
